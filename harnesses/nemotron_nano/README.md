# Nemotron Nano Harnesses

`base.yaml` is the minimal comparison harness. `optimized.yaml` enables the
state ledger, context compaction, conditional audit, tool recovery, and
benchmark-specific completion gates implemented in `nano_harness/`.

Run configs under `configs/benchmarks/` inline these values so every recorded
result is self-contained. These files are the canonical strategy defaults for
new experiments.
